# materia

[Materia](https://primamateria.systems) is a system automation tool that
manages containers and services via systemd quadlets.

Binaries are downloaded from the
[upstream GitHub releases](https://github.com/stryan/materia/releases).

This sysext ships the `materia` binary only. Deployment configuration
(quadlets / service units) is environment-specific — see the
[upstream docs](https://primamateria.systems/documentation/latest/running.html).

## Compatibility

This sysext is compatible with all Fedora variants (CoreOS, Atomic Desktops,
etc.).
