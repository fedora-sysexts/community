# Klassy

[Klassy](https://github.com/paulmcauley/klassy) is a highly customizable window decoration and application style plugin for the KDE Plasma desktop.

This sysext is compiled from source with Qt6 support only (`-DBUILD_QT5=OFF`), as Fedora Kinoite does not include Qt5/KF5 packages by default and bundling them is unnecessary.

## Compatibility

Tested and verified on Fedora Kinoite 44.
